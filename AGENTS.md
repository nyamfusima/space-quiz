# Project guidance

- Keep the quiz self-contained in `index.html`; it must run directly from `file://` without a server, build step, or external dependencies.
- Preserve the existing responsive mission-control design, light/dark color schemes, and reduced-motion support.
- Keep interactions keyboard accessible: maintain visible focus, logical focus movement, accessible feedback, and progress announcements.
- When changing quiz behavior, verify the 10-question flow, answer feedback, score, and results screen in the integrated browser.
- Prefer small, accessible HTML/CSS/JavaScript changes that follow the existing patterns.
